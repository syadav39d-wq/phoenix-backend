# PHOENIX Backend

Node.js API for the PHOENIX Wix frontend.

## Environment variables
- DATABASE_URL
- ADMIN_PASSWORD
- SESSION_SECRET
- ALLOWED_ORIGIN

## Endpoints
- GET /api/health
- GET /api/telemetry
- POST /api/inquiries
- POST /api/test-drives
- POST /api/admin/login
- GET /api/admin/requests
- PATCH /api/admin/requests/:id
